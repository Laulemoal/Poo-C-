# GymManagerLite 

Aplicación web liviana para la gestión básica de un gimnasio.  
El proyecto funciona **exclusivamente del lado del frontend**, utilizando **JavaScript y LocalStorage** para la persistencia de datos.

Está pensado como un **MVP / proyecto de práctica** enfocado en lógica de negocio y manipulación del DOM, sin backend ni base de datos externa.

---

## Funcionalidades

- Gestión de clientes
- Registro de servicios / planes
- Control básico de ventas
- CRUD completo
- Búsqueda y filtrado de registros
- Persistencia de datos mediante LocalStorage

---

## Tecnologías utilizadas

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla)

### Persistencia
- LocalStorage (navegador)
